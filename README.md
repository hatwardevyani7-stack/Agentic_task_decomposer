# Agentic AI Task Planning System

An agentic AI workflow framework built with Python. It automatically decomposes complex user objectives into structured, execute plans.

# Features
- Goal Decomposition: Breaks high-level inputs into structured sub-tasks.
- Structured Output: Strictly enforces JSON response schema for downstream agent pipelines.
- Lightweight Architecture: Single-turn execution designed for fast integration.
